 📨 Telegram Анонимный Бот с Премиум‑функциями

Давно хотели узнать, кто вам пишет плохие анонимные сообщения? Этот бот для вас!  
Бот позволяет получать анонимные сообщения по персональной ссылке, отвечать на них, блокировать отправителей и, при наличии премиума, даже узнавать, кто скрывается за сообщением.  

---

 ✨ Основные возможности

- 🔗 Персональная ссылка для каждого пользователя  
- 🧩 Кастомные ссылки (свой текст вместо случайного кода)  
- 💬 Анонимные сообщения: текст, фото, видео  
- 💌 Ответы на сообщения прямо через бота  
- ⛔ Личные блокировки нежелательных отправителей  
- 🚫 Глобальный бан пользователей админом  
- ⭐ Премиум‑система в отдельной базе `premium_users.db`  
- 🛠 Удобная админ‑панель для управления ботом и пользователями  

---

 👥 Как это работает для пользователя

1. Напишите боту `/start`.  
2. Бот создаст для вас уникальную ссылку вида:  
   `https://t.me/<bot_username>?start=<unique_code>`  
3. Разместите эту ссылку:
   - в описании профиля Telegram  
   - в Instagram / TikTok / других соцсетях  
4. Любой, кто перейдёт по ссылке, сможет отправить вам анонимное сообщение:
   - 💬 текст  
   - 📷 фото + подпись  
   - 🎥 видео + подпись  

Вы получите сообщение от бота, а не от отправителя — его личность останется скрытой (если он не попал под премиум‑функции).

---

 🧩 Кастомные ссылки

- Можно заменить случайный код на красивый кастомный:  
  пример: `my_link`, `best_page123`  
- Допускаются:
  - латинские буквы  
  - цифры  
  - символы `_` и `-`  
  - длина от 3 до 20 символов  
- При желании всегда можно вернуться к оригинальной ссылке.  

---

 💌 Ответы на сообщения

Под каждым входящим сообщением:

- кнопка **«Ответить»** — позволяет написать ответ отправителю  
- ответ отправляется в личку отправителя от имени бота  
- поддерживаются ответы:
  - текстом  
  - фото + текст  
  - видео + текст  

Таким образом, диалог остаётся анонимным для отправителя, но при этом вы можете вести общение.

---

 ⛔ Блокировки

Каждый пользователь может защититься от спама и токсичных сообщений.

 Личный бан

- Кнопка **«Заблокировать»** под сообщением.  
- Заблокированный пользователь больше не сможет отправлять вам сообщения через вашу ссылку.  
- Управление блокировками:
  - `/banlist` — показывает список всех заблокированных  
  - `/unban @username` — разблокировка по username  

 Глобальный бан

- Главный админ может полностью заблокировать пользователя в боте.  
- При глобальном бане бот полностью игнорирует этого пользователя.  

---

 ⭐ Премиум‑система

Премиум хранится в отдельной базе `premium_users.db`, полностью независимо от основной БД.

 Что даёт премиум

- 👁 Кнопка **«Узнать отправителя»** под сообщением  
- Отображается:
  - имя  
  - username (если есть)  
  - Telegram ID отправителя  

 Управление премиумом

Только через админ‑панель:

- выдача премиума на N дней  
- продление срока  
- полное снятие премиума  

Все премиум‑данные:

- хранятся в файле `premium_users.db`  
- управляются через модуль `premium_db.py`  
- не зависят от `bot_database.db`

---

 🛠 Админ‑панель

Доступна только главному администратору (`MAIN_ADMIN_ID` в коде).

 Как открыть

- Выполнить `/start`  
- Появится кнопка **«⚙️ Админ панель»**  

 Возможности админ‑панели

- 👥 Список пользователей:
  - ID, имя, username  
  - персональная и кастомная ссылка  
  - премиум‑статус  

- ⭐ Работа с премиумом:
  - выдать премиум на:
    - +1 / +3 / +5 / +7 дней
    - или любое количество дней вручную  
  - снять премиум с пользователя  

- 🚫 Глобальный бан:
  - добавить пользователя в глобальный бан  
  - снять глобальный бан  

- 👁 Кто заблокировал пользователя:
  - список пользователей, которые внесли его в личный бан  
  - отдельный акцент на премиум‑пользователях  
  - разбан у конкретного пользователя по кнопке  

---

 🗄 Структура проекта

- `config.py`  
  Основной файл бота:
  - запуск Telegram‑бота  
  - обработка команд `/start`, `/admin`, `/unban`, `/banlist`  
  - обработка сообщений и callback‑кнопок  
  - работа с основной базой `bot_database.db`  

- `premium_db.py`  
  Работа с премиум‑пользователями:
  - отдельная база `premium_users.db`  
  - функции:
    - `is_premium(user_id)`  
    - `add_or_extend_premium(user_id, days)`  
    - `remove_premium(user_id)`  
    - `list_premium_users()`  

- `bot_database.db`  
  Основная SQLite‑база:
  - `user_links` — пользователи и их ссылки  
  - `messages` — анонимные сообщения  
  - `blocked_users` — личные блокировки  
  - `replies` — ответы на сообщения  
  - `global_ban_users` — глобальные баны  

- `premium_users.db`  
  База премиум‑пользователей:
  - `premium_users(user_id, premium_until)`

 🚀 Установка и запуск

 1. Клонирование репозитория

git clone https://github.com/kkaifddkk/telegram-anonymous-feedback-bot.git
cd <your-repo>



 2. Установка зависимостей

pip install -r requirements.txt



 3. Настройка

В файле `config.py`:

- вставьте токен бота от BotFather в `YOUR_BOT_TOKEN_HERE`  
- укажите `MAIN_ADMIN_ID` — ваш Telegram ID  

 4. Первый запуск

python config.py



При первом запуске:

- создаётся `bot_database.db`  
- создаётся `premium_users.db`
